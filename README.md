# 📊 Sales Performance Analysis Dashboard (Excel)

An interactive, dynamic sales analytics dashboard built in Microsoft Excel using Pivot Tables, Pivot Charts, and Slicers. The project analyzes commercial performance across global regions, product categories, and historical timelines using the Global Superstore dataset.

## 🎯 Key Objectives & Deliverables

- *Total Revenue KPI:* Tracked cumulative gross revenue ($12.64M) across all global transactions.
- *Category-wise Distribution:* Visualized sales contributions by top categories (Technology, Furniture, and Office Supplies) using a Doughnut Chart.
- *Department & Sub-Category Performance:* Horizontal Bar Chart ranking high-earning sub-categories (e.g., Phones, Copiers, Bookcases).
- *Multi-Year Sales Trends:* Line chart evaluating annual revenue growth trajectories between 2012 and 2015.
- *Dynamic Cross-Filtering:* Integrated interactive Slicers (Market and Region) connected to all Pivot Tables for instant segmented reporting.

---

## 🛠️ Tools & Techniques Used

- *Tool:* Microsoft Excel
- *Data Transformation:* Data cleaning, type conversion, and structuring into structured Excel Tables (Ctrl + T).
- *Pivot Tables & Summarization:* Multi-dimensional aggregation, grouped time series (Yearly hierarchy), and currency formatting.
- *Pivot Charts:* Doughnut charts, Horizontal bar charts, and Line graphs with custom legends and data labels.
- *Interactive Controls:* Slicers with customized multi-pivot report connections.
